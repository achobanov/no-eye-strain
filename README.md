# no-template
Mostly tech-agnostic repository template

## Built-in
- [RTK](https://www.rtk-ai.app/)
- [Matt Pocock skillset](https://github.com/mattpocock/skills/tree/main#2-run-setup-matt-pocock-skills)
- sync.sh - execute locally to sync latest changes from `master` and `develop` branches into your `feature*` branch before pushing

## Install
1. Run `setup-matt-pocock-skills` skill - [link](https://github.com/mattpocock/skills/tree/main#2-run-setup-matt-pocock-skills)
